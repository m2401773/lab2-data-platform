# Порядок блокировки и разблокировки аккаунта

## Причины блокировки
Аккаунт блокируется при задолженности больше 1000 рублей, при повторном нарушении правил парковки или при подозрении на передачу аккаунта третьим лицам.

## Разблокировка
Для разблокировки клиент погашает задолженность. Если блокировка была за нарушение, решение о разблокировке принимает старший смены поддержки в течение 24 часов.

## История блокировок
Все изменения статуса аккаунта сохраняются в истории клиента. Бухгалтерия использует историю статусов для сверки начислений.
